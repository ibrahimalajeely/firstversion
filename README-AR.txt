تثبيت «النسخة الأولى» على الموبايل كتطبيق (أسهل من APK)
=========================================================
هذا المجلد موقع جاهز. ترفعه مرة وحدة على الإنترنت مجاناً، وبعدها تثبته من الموبايل بزر واحد،
ويطلع أيقونة على الشاشة الرئيسية ويشتغل بدون إنترنت.

الخطوة 1: رفع الموقع (GitHub Pages — مجاني)
  1) ادخل github.com وسجّل حساب (أو سجل دخول).
  2) اضغط + ثم New repository. اكتب اسم مثل firstversion واختر Public ثم Create repository.
  3) اضغط "uploading an existing file" وارفع كل الملفات اللي بهذا المجلد
     (index.html و manifest.webmanifest و sw.js و icon-192.png و icon-512.png و .nojekyll) ثم Commit changes.
  4) Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Save.
  5) بعد دقيقة يظهر الرابط بأعلى الصفحة مثل: https://اسمك.github.io/firstversion/

الخطوة 2: التثبيت على الموبايل
  - أندرويد (Chrome): افتح الرابط ← قائمة النقاط الثلاث ← "تثبيت التطبيق" أو "Add to Home screen".
  - آيفون (Safari): افتح الرابط ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
  افتح البرنامج مرة وحدة وأنت متصل بالإنترنت حتى يحفظ نفسه، وبعدها يشتغل بدون إنترنت.

للحصول على ملف APK حقيقي من نفس الرابط:
  افتح pwabuilder.com ← الصق الرابط ← Start ← Package for stores ← Android ← Generate، ونزّل الـ APK.

ملاحظات:
  - بياناتك تنحفظ داخل المتصفح على الموبايل. خذ نسخة احتياطية دورياً من الإعدادات ← النسخ الاحتياطي.
  - لا تمسح بيانات متصفح Chrome (Clear site data) حتى لا تضيع البيانات.
  - للتحديث: استبدل ملف index.html بالنسخة الجديدة بنفس المستودع، وسيتحدث التطبيق تلقائياً عند الاتصال.
